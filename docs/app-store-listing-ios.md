# App Store listing (iOS 1.1.0)

The App Store's fields, filled from [store-listing.md](store-listing.md) (the
Play listing) so both stores say the same thing. Where iOS differs from
Android, the text differs too: no home screen widgets on iPhone, sign-in with
Google or Apple, and subscriptions are managed in the Apple ID settings.

Same rules as the Play text (store-listing.md §1): no prices, no "free" in the
name or subtitle, no promised results, counts as floors.

## App Privacy (nutrition labels)

From [play-data-safety.md](play-data-safety.md) §2. Nothing is used for
tracking; nothing is linked to the user except the backup's user id.

**Do you or your third-party partners collect data from this app?** Yes.

| Apple data type | Linked to the user | Tracking | Purpose |
|---|---|---|---|
| Health & Fitness → Fitness | Yes (backup is under the sign-in id) | No | App Functionality |
| Health & Fitness → Health | Yes | No | App Functionality |
| Identifiers → User ID | Yes | No | App Functionality |
| Identifiers → Device ID | No | No | Analytics, App Functionality |
| Purchases → Purchase History | No | No | App Functionality |
| User Content → Photos or Videos | No | No | App Functionality |
| User Content → Other User Content | No | No | App Functionality |
| Usage Data → Product Interaction | No | No | Analytics |
| Diagnostics → Crash Data | No | No | Analytics, App Functionality |
| Diagnostics → Other Diagnostic Data | No | No | Analytics, App Functionality |

Not collected: Contact Info (the email and name arrive inside the sign-in token
and are never stored), Location, Sensitive Info, Contacts, Financial Info other
than purchases, Browsing History, Search History, Audio, Gameplay Content,
Customer Support, Other Data.

"Health": body weight and measurements, and anything a reader writes into a
coach question. "Fitness": the workout log.
